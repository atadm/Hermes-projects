# Workshop 2 — Instrument Selection

**Time:** 90 min · **Output:** kept/adapted/dropped instrument list, template owners, storage decision

## Objective

Choose the toolkit. Every instrument on the playbook list (§3) gets a decision: **keep, adapt, or drop**. Assign an owner per kept template. Decide where templates live (single source of truth).

## Prep (before the session)

- Facilitator: prepare the instrument list (playbook §3, 27 items) as cards on a board (Confluence whiteboard / Figma / sticky notes).
- Prepare short demos of the built templates: intake, triage scorecard, ROI model, business case canvas, steering 1-pager, RAID log, decision log, adoption + benefit trackers.
- Research the storage options beforehand (Confluence space? repo? both?) so the choice is informed, not invented in the room.

## Attendees

EPO team. (Finance/Procurement can be invited later for specific templates — don't block the session on them.)

## Agenda

| Time | Segment | Activity |
|---|---|---|
| 0–10 | Setup | The decision rule: **an instrument must be used within a month or it's cut**. Show the 9 already-built templates. |
| 10–40 | Review in groups | Split the 27 instruments into the 6 groups (Economics / Analysis / Selection / Delivery / Change / Measurement). Each group gets 5 minutes to vote keep/adapt/drop. |
| 40–60 | Adapt decisions | For each "adapt": what changes? (fields, wording, format). Assign a template owner. For "drop": record why (revistable later). |
| 60–75 | Storage & access | Decide: where do templates live, who can edit, versioning rule. Options: Confluence space (recommended for team adoption) vs repo as canonical source + Confluence copies. |
| 75–90 | Wrap-up | Confirm the minimal set (playbook §3); owners list; what gets used on which live project in the next 30 days |

## Facilitation tips

- The built templates are **starting points, not gospel** — the team should feel free to adapt them.
- Watch for template inflation: someone will want to add instruments. Apply the 30-day rule.
- If the storage decision stalls, default: **repo is canonical, Confluence hosts working copies** — revisit in 3 months.

## Outputs & follow-ups

- [ ] Kept/adapted/dropped list → update playbook §3
- [ ] Template owners assigned (one per kept template)
- [ ] Storage decision → update playbook §4 / README
- [ ] First 3 templates to use on live projects in the next 30 days, with owners
- [ ] Decision log entries from the session

## Success criteria

- Every instrument on the list has a decision (no undecided items).
- Every kept template has a named owner.
- Storage and versioning are agreed.
