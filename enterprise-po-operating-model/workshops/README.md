# Workshop Pack — Enterprise PO Operating Model

**Purpose:** Turn the playbook + templates from a repo into the team's actual way of working. Three 90-minute sessions, each producing a concrete, usable output. Sessions can run weekly, or back-to-back in one day (add breaks).

## Sessions

| # | Session | Output | Who should attend |
|---|---|---|---|
| 1 | [Role & Process](workshop-1-role-process.md) | Adapted process map, gate definitions of done, role boundaries | EPO team + 1–2 process owners |
| 2 | [Instrument Selection](workshop-2-instruments.md) | Kept/adapted/dropped instrument list, template owners, storage decision | EPO team |
| 3 | [Governance & Metrics](workshop-3-governance-metrics.md) | Decision rights table, steering charter, KPI definitions | EPO team + sponsor + Finance (for ROI convention) |

## Sequencing guidance

- **Run W1 first** — everything else depends on the agreed process.
- W2 and W3 can be swapped if the team feels the governance questions are more urgent than template choices.
- If time is short: W1 + W3 (process + governance) are the critical pair; W2 can be done async with a voting doc.

## Materials checklist (per session)

- [ ] Playbook printed or on screen (the session walks specific sections)
- [ ] Confluence whiteboard / Figma board / physical sticky notes + wall (see tooling note: no Miro)
- [ ] Decision Log template open (every session ends with logged decisions)
- [ ] Timer for timed agenda segments
- [ ] Session-specific prep (listed in each session doc)

## Facilitation rules (all sessions)

1. **Start from real projects, not theory.** If a topic doesn't connect to a real project someone owns, it's off-topic.
2. **Decisions are recorded as you go** — decision log entries during the session, not after.
3. **No template inflation.** The standing rule: an instrument must be used within a month or it's cut.
4. **Every session ends with:** decisions made, owners named, next step dated.
5. **Keep it lean** — 90 minutes is a constraint, not a suggestion.

## Success signal

After all three sessions: any EPO can answer "what phase is my project in, what's the next gate, who decides, and which instrument do I use next" without asking anyone.
